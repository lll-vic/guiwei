# 归位 Guiwei

面向 Mac 个人文件的本地搜索原型。输入记得的正文线索，查看命中段落，并排核对两个版本。

## 运行

需要 Python 3.11 或更新版本。

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

打开终端显示的完整本机链接（含随机访问令牌）。在“管理文件夹”中填写目录路径。服务仅监听 `127.0.0.1`，没有对外网络调用。不要公开启动链接。

## 当前能力

- 递归读取用户选择的目录，支持 PDF、DOCX、TXT、MD。
- PDF 按页显示命中原文；DOCX 按段落显示，排除已删除修订。
- 关键词、中英文词项及中文相邻字匹配，支持输入句子；**不是 embedding 语义搜索**，不能保证理解同义改写、否定条件或“最全面”等主观要求。
- 结果提供原路径、正文快照、两个候选版本的并排段落对照；PDF 可打开原件预览。
- 明示 Pages、旧 DOC、加密 PDF、无可提取文字等读取问题。
- 单份文件支持手动“删除本地原文件”：显示文件名及完整路径，用户再次确认才移入 Mac 废纸篓。默认焦点是取消；取消或 Escape 不删除。搜索、索引、刷新、对比均不会触发删除。
- 无永久删除或清空废纸篓功能；废纸篓操作失败不会回退到永久删除。可在 Finder 废纸篓找回，再重新读取目录。
- 每次确认需要短时、一次性凭据；执行前检查范围及文件身份/修改状态。旧凭据、变动文件和索引过程中均拒绝操作。
- 用户材料和索引仅存在本机内存，不写入仓库。

## 已知边界

索引非实时：文件变化后点击“重新读取”。最多收录 20,000 个普通文件。跳过隐藏/临时文件、符号链接、应用包、开发依赖及本项目目录。先按扩展名分类，再自动读取最多 200 份支持的文档（简历优先），其余明确标记正文待读，可点击按需读取。正文及缩略图单份 30 MB，PDF 最多 250 页。图片缩略图通过 Pillow 在本机生成，HEIC 等格式可能无法预览，但仍可分类和查找名称。截图类别按文件名线索识别，文字通过本机 OCR 提取；支持手动纠正分类，仅在当前服务运行中保存。不支持扫描 PDF OCR、Pages 正文、系统全局快捷键、自动差异判定或 AI 语义排名。表格与复杂版式的提取顺序可能有误，请核对原件。

本版本验证“记忆线索 → 候选 → 原文 → 版本确认”。后续依据使用反馈决定是否引入本地语义索引与可撤销整理。

```sh
.venv/bin/python -m unittest discover -s tests -v
```

测试使用临时虚构文件，不包含个人简历。真实资料不得提交至 GitHub。

删除测试以 mock 替代系统废纸篓调用，验证读操作无副作用、取消、过期、重复提交、文件变化与失败分支，不删除用户文件。前端仅从可信点击事件进入确认流程；这属于应用交互约束，不能防御已获得本机权限和访问令牌的恶意程序。

### 截图文字搜索

扫描目录后，会自动使用 macOS Vision 在本机识别截图及图片中的简体中文和英文文字，显示处理进度，并将文字加入现有搜索。普通图片也自动识别，优先处理截图。结果展示命中文字和图片预览。无文字和识别失败分别标注；单张图片上限 30 MB，识别超时 45 秒。

首次运行会通过 Xcode Command Line Tools 编译 `native/ocr.m` 到忽略目录 `.local`；本机无兼容工具时显示 OCR 未就绪。识别内容只留在进程内存，重启需重新索引；同次运行中重新扫描可复用未变化图片的识别结果。不会上传图片、修改原图或自动删除。

当前是识别文字后的关键词匹配，不支持仅凭画面描述或完全不同措辞的语义检索。小字、模糊、手写内容可能遗漏。扫描 PDF 的 OCR 尚未接入。

截图分组内新增工作学习、求职申请、旅行生活、其他主题筛选，按文件名和 OCR 关键词建议，可手动修改（当前运行内保存）。主题筛选不影响“全部文件”的统一搜索，也不改变其他顶级分类。

## 首次使用与反馈

这是 v0.1.0 本地 MVP，面向 macOS；不是已签名的独立安装包。OCR 需要 Apple Command Line Tools（可通过 `xcode-select --install` 安装）。安装依赖后，可双击 `启动归位.command` 或使用上方终端命令启动。

1. 打开启动链接，点击“扫描整个桌面”，或添加一个指定文件夹。
2. 目录先显示，文档及图片文字随后逐步读取；未识别的内容暂不能检索。
3. 在“全部文件”输入记得的词句；在“截图”里按主题缩小范围。
4. 查看命中原文和图片，对比版本。分类只影响应用显示，不移动或重命名原文件。
5. 重启服务后需重新扫描，手动分类也不会跨重启保留。

反馈请通过 GitHub Issues，描述预期、实际结果和复现步骤。使用虚构样本，切勿附带敏感个人文件。

## 实现

Python 标准库 HTTP 服务提供本机 API；原生 HTML/CSS/JavaScript 提供界面；pypdf 和 DOCX XML 提取正文；Apple Vision 辅助进程读取图片文字。检索使用可解释的关键词与中文相邻字匹配，截图主题使用规则建议。没有调用云端模型，也没有账号或遥测服务。
